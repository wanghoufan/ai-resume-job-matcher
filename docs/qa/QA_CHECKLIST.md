# QA_CHECKLIST — 长期核心回归测试

> 本文件是项目的**长期核心回归基线**，由 `技术规划师` 在首次形成 `PLAN.md` 或新增核心功能 / 实体时建立，由 `QA` 根据真实测试持续补充高价值回归项。`neat-freak` 在重要阶段负责修剪、去重和更新。
> 与「本轮专项 / 探索性测试」互补：本文件管长期回归，本轮测试管当前变更。
